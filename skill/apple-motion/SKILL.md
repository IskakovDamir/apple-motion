# apple-motion

the component library in `templates/remotion/` as the starting point. Not affiliated with Apple.

## Workflow

1. **Script in beats, not seconds.** Write the copy as short cards: 1-4 words per line, max 2 lines
   (headline) or a number + a 2-4 word caption. Decide BPM first (see audio), then give every card a
   length in beats. At 30 fps and 120 BPM one beat is 15 frames, one bar 60.
2. **Voice-over leads, music follows.** If there is VO, put the type on the spoken word (text lands
   a few frames *before* the word, see `typography.vo_offset`), and cut on phrase boundaries. Without
   VO, cut on beats and put hits on downbeats.
3. **Pick entries from the measured mix.** Default: `scaleDown` (slightly large -> 1.0 with a little
   blur) and hard `cut` on. Use `perWord` for lists and punchlines, `slideUpMask` for left-aligned
   statements, `Counter` for numbers. Exits are mostly the cut itself.
4. **Build with the templates.** Copy `templates/remotion/` into `src/apple-motion/`, then compose
   with `<TransitionSeries>`; `appleTransition()` returns the measured transitions; cuts are just the
   next `<TransitionSeries.Sequence>`.
5. **Mix.** Music bed + SFX on transitions, master to the measured loudness (ffmpeg `loudnorm`).
6. **Self-check.** Run `scripts/check_render.py out.mp4` and fix anything outside the Apple ranges.

## Hard rules

- Type: SF Pro Display (Semibold for headlines) via the system font stack; Inter as the fallback
  off Apple platforms. Tight tracking (-0.01 to -0.02 em), leading ~1.05. Never outline, shadow,
  gradient-fill or box the type.
- Colour: type is white on black/footage or near-black (#1d1d1f) on white/#f5f5f7. Colour comes
  from the picture (product, UI, gradient fields), not from the type.
- Motion: springs are critically damped or close to it - no visible bounce on type. Never rotate
  type, never bounce it, never letter-spin. Entries are short; holds are short; exits are cuts.
- Pace: the median shot is short (see numbers). If a card holds longer than ~2 s, something must
  move (slow push, UI animation, counter).
- Transitions: >90% hard cuts. Whips, dissolves, mask wipes and scale-throughs are accents - one
  every few seconds at most, usually on a musical accent.
- Remotion specifics: `spring()` with `durationInFrames` stretches to that length; damping above
  `2*sqrt(stiffness*mass)` behaves exactly like critical damping in Remotion (measured in the port
  test), so "more damping" stops changing anything past that point.

## Components (templates/remotion)

| file | what |
|---|---|
| `tokens.ts` | measured defaults (springs, beziers, durations, type scale, colours, loudness) - generated |
| `KineticText.tsx` | `<KineticText lines entry exit size align x y durationInFrames/>`; entries: cut, fade, blurIn, scaleDown, scaleUp, slideUp, slideUpMask, perWord, perLetter; exits: cut, fade, blurOut, scaleUp, slideOut |
| `Counter.tsx` | number roll with tabular figures |
| `transitions.tsx` | `appleTransition('whip' / 'dissolve' / 'maskWipe' / 'scaleThrough', key)` for `TransitionSeries` |
| `beat.ts` | `beatGrid(bpm, fps)`, `onBeat`, `onBar`, `snap`, `beats` |
| `Sfx.tsx` | `<Sfx name at/>` with pre-roll so the transient lands on `at` |
| `Backdrop.tsx` | black / white / #f5f5f7 / slow gradient fields |

Minimal composition:

```tsx
import {TransitionSeries} from '@remotion/transitions';
import {Html5Audio, staticFile} from 'remotion';
import {appleTransition, Backdrop, beatGrid, beats, KineticText, Sfx} from './apple-motion';

export const Recap = () => {
  const g = beatGrid(120, 30);
  return (
    <>
      <Html5Audio src={staticFile('music.wav')} />
      <TransitionSeries>
        <TransitionSeries.Sequence durationInFrames={beats(g, 4)}>
          <Backdrop kind="black"><KineticText lines={['Faster.']} durationInFrames={beats(g, 4)} entry="scaleDown" size="hero" /></Backdrop>
        </TransitionSeries.Sequence>
        {appleTransition('whip', 't1')}
        <TransitionSeries.Sequence durationInFrames={beats(g, 4)}>
          <Backdrop kind="white"><KineticText lines={['Every app.', 'Every day.']} durationInFrames={beats(g, 4)} entry="perWord" color="#1d1d1f" /></Backdrop>
        </TransitionSeries.Sequence>
      </TransitionSeries>
      <Sfx name="whoosh" at={beats(g, 4) - 4} />
    </>
  );
};
```

Keep every card starting on its beat: when a transition overlaps two cards, extend the outgoing card by
the transition length instead of pulling the next card earlier (see `demo/src/Recap.tsx`).
